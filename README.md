# java-expense-tracker
An Android personal finance and expense tracking application developed using Java and Android Studio.

## About the Project
Expense Tracker is an Android application developed using Java and Android Studio. It helps users manage their personal finances by recording income and expenses and viewing their financial balance.

## Features
- Monthly salary and currency setup
- Income and expense recording
- Transaction categories and notes
- Financial summary dashboard
- Transaction history
- Offline functionality
- Local data storage

## Technologies Used
- Java
- Android Studio
- XML
- Material Components
- SharedPreferences
